# ISOMETRIC LAB
### TOPIK 10 Proyeksi Piktorial Isometri: Normal • Terbalik • Horizontal

**ISOMETRIC LAB** adalah media pembelajaran interaktif berbasis CAD yang dirancang untuk membantu pengguna mempelajari dan mempraktikkan teknik menggambar proyeksi piktorial isometri.

## Fitur Utama
- Pembelajaran Isometri Normal, Terbalik, dan Horizontal.
- Simulasi sumbu dan orientasi proyeksi isometri.
- CAD Workspace untuk menggambar objek 3D.
- Tantangan menggambar dengan tingkat Beginner, Intermediate, dan Advanced.
- Sistem progres dan penilaian.
- Ekspor hasil gambar.

## Tujuan Pembelajaran
Meningkatkan keterampilan pengguna dalam memahami dan menerapkan proyeksi piktorial isometri melalui latihan menggambar objek geometris dan komponen mekanik.

## Cara Mengakses
1. Buka tautan aplikasi ISOMETRIC LAB.
2. Masuk ke halaman utama.
3. Pilih materi pembelajaran atau CAD Challenge.
4. Kerjakan tantangan menggambar secara berurutan.
